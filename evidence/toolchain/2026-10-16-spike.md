## Limitations and decisions required

- The selected Flutter version supports an API 24 host baseline by default. API 23 was not established for the Flutter example, so ADR 0003 requires a human-approved amendment to API 24 or a different Flutter toolchain decision.
- Gradle emitted an SDK XML warning stating that its SDK parser understands XML through version 3 while version 4 metadata was present. The build passed, but the Android command-line tools should be aligned or this warning explicitly accepted before production scaffolding.
- The generated example declares NDK 28.2.13676358 even though the empty plugin has no native dependency. The production scaffold must test removal rather than inheriting an unnecessary NDK declaration.
- No emulator, device, camera, scanner, accessibility, security-runtime, clean-host, or distribution behavior was tested. Those were outside the spike.
- Xcode and CocoaPods findings are irrelevant because iOS is excluded.
